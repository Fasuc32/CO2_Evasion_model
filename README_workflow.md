# Stream CO2-evasion modelling workflow

This repository documents two linked R Markdown scripts used to prepare input data and estimate CO2 evasion with an isotope-based inverse model.

## Workflow

1. **`01_weathering_correction.Rmd`**  
   Combines the cleaned sample database with MEGA geochemical-model outputs, applies the weathering correction, recalculates corrected carbon-isotope compositions, and writes `Weathering_modelling.csv`.

2. **`02_isotope_based_CO2_evasion_model.Rmd`**  
   Uses the weathering-corrected data from Step 1 to fit the inverse degassing model for each sample and writes `Evasion_Modelling_RW_DIC_pH_CO2.csv`.

## Input data

The input datasets are not included in this repository. To reproduce the workflow, provide local copies of:

- `CleanDatabase.csv`
- `MEGA_Modelling.csv`
- `Weathering_modelling.csv` (generated by Step 1 and used by Step 2)

Update the example file paths in each script before running it. The R Markdown files are set up to render as workflow documentation without executing code chunks when knitted, because the required data are not distributed with the scripts. Execute the code chunks in order after configuring the input and output paths.

## Software

The scripts use R and the `tidyverse` package. Step 2 uses functions from `purrr` and `tidyr`, which are included in `tidyverse`.

## Outputs

- `Weathering_modelling.csv`
- `Evasion_Modelling_RW_DIC_pH_CO2.csv`

## Scope and implementation note

The scripts document the workflow used in the analysis. The equations and model settings are retained from the supplied scripts; publication of this workflow should not be interpreted as independent validation of the numerical implementation. Before reproducing the inverse model, verify unit consistency in the alkalinity calculations: carbonate-species concentrations inherit the units of DIC, while H+ and OH− are calculated in mol L⁻¹.
